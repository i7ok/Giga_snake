# Гига Змейка

Простая браузерная игра «Змейка» в одном файле. Управление стрелками или клавишами WASD (в английской раскладке).

## Что было не так

Код игры сгенерировал ГигаЧат, и он накосячил с начальным положением змейки. В `startGame()` он расположил её так:

```js
snake = [
    {x: 8, y: 10},   // голова (snake[0])
    {x: 9, y: 10},
    {x: 10, y: 10}
];
dx = 1;  // движение вправо
```

Голова стояла слева, а тело справа от неё, при этом змейка двигалась вправо. На первом же шаге голова врезалась в собственное тело, и игра заканчивалась, не успев начаться: на поле ничего не рисовалось, сразу появлялась кнопка «Играть снова», а перезапуск ничего не менял.

## Как исправлено

Порядок сегментов перевёрнут: голова теперь впереди по направлению движения, тело позади.

```js
snake = [
    {x: 10, y: 10},  // голова
    {x: 9, y: 10},
    {x: 8, y: 10}
];
```

Больше в файле ничего не менялось: структура, стили и остальная логика остались прежними.
