# Змейка 2.0

Простая браузерная игра «Змейка» в одном файле `index.html`. Управление стрелками или клавишами WASD (в английской раскладке).

## Что было не так

Код игры сгенерировал ГигаЧат, и он накосячил с начальным положением змейки. В `startGame()` он расположил её так:

```js
snake = [
    {x: 8, y: 10},   // голова (snake[0])
    {x: 9, y: 10},
    {x: 10, y: 10}
];
dx = 1;  // движение вправо
```

Голова стояла слева, а тело справа от неё, при этом змейка двигалась вправо. На первом же шаге голова врезалась в собственное тело, и игра заканчивалась, не успев начаться: на поле ничего не рисовалось, сразу появлялась кнопка «Играть снова», а перезапуск ничего не менял.

## Как исправлено

Порядок сегментов перевёрнут: голова теперь впереди по направлению движения, тело позади.

```js
snake = [
    {x: 10, y: 10},  // голова
    {x: 9, y: 10},
    {x: 8, y: 10}
];
```

Больше в файле ничего не менялось: структура, стили и остальная логика остались прежними.

## Как запустить

Откройте `index.html` в браузере. Чтобы опубликовать на GitHub Pages, загрузите файл в репозиторий и включите Pages: *Settings → Pages → Deploy from a branch → `main` / root*.

## Что в игре осталось как было

Эти особенности не исправлялись:
- выход за край поля завершает игру;
- нет сенсорного управления;
- WASD не работает в русской раскладке;
- при двух быстрых нажатиях между шагами змейка может развернуться на 180° и врезаться в себя.
